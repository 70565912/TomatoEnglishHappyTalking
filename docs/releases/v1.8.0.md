# Tomato English Happy Talking v1.8.0

发布日期：2026-08-30

## 主要更新

- 英文朗读分句内部求解器升级为 `syntax_solver_v3_10`。
- 直/弯单双引号与圆括号共用统一 delimiter scanner；关闭符归左块、打开符归右块。
- 支持 `’ ‘`、`’‘`、`' '`、`''` 等相邻说话回合边界，同时避免把 contraction、所有格、
  `’Twas`、`'em` 或未闭合引号误配成完整引语。
- 新增同一 DAG 的只读候选覆盖诊断。候选上限仍为初轮 8 条、扩展 24 条；没有书籍白名单、
  固定路径保送、第二次 DP 或 Bridge/数据库协议变化。

## 验证结果

- 55/55 局部审核单元通过。
- 243/243 原生 UDPipe 结构金标支持认可路径。
- Alice 39章与 Willows 62章默认首选相对接受基线无新增变化。
- Looking Glass 只保留既定14组 delimiter 修正；C32 为 `13/6/12`，C52 保持 `16/6/6`。
- 五组同机 AOT 交替基准均扩展至9轮，没有明确中位数性能回退。
- 6,757句发布持久化 fixture 只读验证，未重新生成或迁移。

## 下载与升级

- Windows：下载 `tomato_english_happy_talking-windows-v1.8.0.zip`，解压后运行 EXE。
- Android：下载 `tomato_english_happy_talking-android-v1.8.0.apk`；当前为项目测试签名侧载包，
  不是应用商店签名。
- 使用 `SHA256SUMS.txt` 校验下载文件完整性。

Windows ZIP 不包含开发者或用户的数据库、API Key、缓存、日志、录音、绘本、歌曲及导出媒体。
Windows 与 Android 正式产物都打包项目声明的本地 Nunito 与图标字体。

> 已保存文章继续读取 `articles.sentences` 中的既有句槽，不会因为升级自动重新分句。
> 新建文章或用户显式重建时才使用 V3.10。

## English summary

V1.8.0 upgrades the internal read-aloud chunker to `syntax_solver_v3_10`, unifies straight/curly
single and double quotes plus parentheses in one scanner, and adds read-only reachability coverage
from the existing bounded DAG. All 55 review units and 243 native structural gold cases pass; the
101 Alice and Willows chapters retain their accepted default boundaries, while Looking Glass changes
remain limited to 14 approved delimiter fixes. Persisted articles are not automatically resegmented.
