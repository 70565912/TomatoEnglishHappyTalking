# Tomato English Happy Talking v1.8.3

发布日期：2026-09-23。应用版本：1.8.3+13；分句求解器：syntax_solver_v3_11。

## 本次更新

- Windows 关闭时保存正常窗口位置、大小和最大化状态，下次启动恢复。宽度小于 320 或高度小于 240 的矩形不保存。
- 听力内联、听力全屏、歌曲内联和歌曲全屏切绘本页时读取录制设置 `pageTransition`。设置变更立即写入本地配置，启动时载入。
- 播放与视频导出共用 `PageTransitionRenderer`。实时播放用 `display` 图片生成固定 `1280x720`、8 帧、500ms 的 PNG，包含 `pageCurl`。帧可以跳过，但不阻塞音频或字幕，最终停在目标页。`none` 或 `prefers-reduced-motion` 时瞬间切换。
- 分句求解器保持 `syntax_solver_v3_11`。本次只补充尾随后置修饰语逗号切分测试，并合并 E13 回归夹具。已保存文章继续使用 `articles.sentences`，不自动重分句。
