# Tomato English Happy Talking v1.1.0

发布日期：2026-07-21（Asia/Shanghai）。相对v1.0.0的更新。

## 本次更新

- 创作中心支持为单个绘本页导入PNG、JPG、JPEG、WebP图片。导入图按该版本规则适配为2560×1440，替换页面图片而不改变分镜，也不调用图片生成API。
- 新增“导出组图”，按场景序号导出本章已就绪图片；遇到同名文件时可覆盖或选择新前缀。
- 改进章节分镜规则：按地点/时间、主视觉焦点和中心任务组织场景，避免把重复小动作拆成过多画面。
- 新AI分镜严格检查连续覆盖、场景数量和描述完整性，不再静默截断多余场景并把剩余内容塞进最后一景。
- 完善中文README、API Key配置指南和界面截图。

## 下载与升级

- Windows：`tomato_english_happy_talking-windows-v1.1.0.zip`，解压后运行EXE。
- Android：`tomato_english_happy_talking-android-v1.1.0.apk`，项目测试签名侧载包，并非应用商店签名。

Windows安装包不包含本机数据库、缓存、日志、API Key或生成媒体。云服务使用用户自行配置的账号。

## English summary

Adds per-page image import and chapter image export with filename-conflict handling. Scene planning uses location/time, visual focus, and the central task, with stricter coverage validation. Chinese documentation and configuration guidance are expanded.
