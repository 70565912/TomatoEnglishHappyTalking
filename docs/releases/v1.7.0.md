# Tomato English Happy Talking v1.7.0

发布日期：2026-08-17（Asia/Shanghai）。相对v1.5.0的更新。

## 本次更新

- 英文朗读分句求解器定版为syntax_solver_v3_9，持久化协议仍为read_aloud_dp_v3 / reviewed_dp_v3。
- 延续单次不可变事实构建和单次有界DAG求解，收敛重复候选与评分路径；相对上一正式公开版本v1.5.0，也包含V3.8阶段的统一求解重构。
- 进一步完善长度、标点和句法边界选择，修复go|on等短语动词误解析切点。
- 当时的Alice/Willows全量对照及嫌疑切点审核记录中，相对数据库裁决的硬错误为0；同机AOT相对V3.8的章级中位耗时下降约4%–31%，全量端到端约下降22%。这些是该版本的历史验证结果。
- Android补齐Cupertino图标字体；火山ASR文案明确区分SeedASR 2.0与可选旧模型BigASR 1.0。
- 升级不会自动改写已保存文章的句槽，离线语料迁移工具与正式App运行链路隔离。

## 下载与升级

- Windows：`tomato_english_happy_talking-windows-v1.7.0.zip`，解压后运行EXE。
- Android：`tomato_english_happy_talking-android-v1.7.0.apk`，项目测试签名侧载包，并非应用商店签名。
- 使用随附`SHA256SUMS.txt`核对下载文件。

Windows安装包不包含本机数据库、缓存、日志、API Key或生成媒体。云服务使用用户自行配置的账号。

## English summary

Finalizes syntax_solver_v3_9 while retaining the shared fact/DAG pipeline and persisted V3 protocol. It refines length, punctuation and syntax decisions, fixes phrasal-verb cuts, bundles Cupertino icons on Android, and clarifies Volcengine ASR model terminology. Historical AOT checks report improvements over V3.8; saved articles are not automatically resegmented.
