# Tomato English Happy Talking v1.8.1

发布日期：2026-09-14

## 主要更新

- 火山 `seed-tts-2.0` 补齐教学 / 有声书 / 客服类英语发音人；设置页可只显示英文声音。
- 设置页把「语音合成」和发音人选择放到顶部，「保存声音」紧随其后；云服务 / 歌曲保存按钮改为醒目主按钮。三套保存仍相互独立。
- 听力全屏、歌曲全屏与歌曲内联切页读取录制设置 `pageTransition`（`none` / `crossFade` / `panZoomFade` / `slide` / `pageCurl`），Web UI 以 CSS 近似；音频不等待转场完成。
- 听力全屏从当前选中句子开始播放。

## 验证结果

- Web UI：设置页声音过滤 / 布局相关测试、全屏听力起点测试、歌曲全屏与 `pageTransition` 切页相关测试已通过。
- Web UI `npm run build` 与 Windows Release 构建已通过。
- 真实播放流畅度依赖本机 WebView；单元测试不能替代主观听感确认。

## 下载与升级

- Windows：下载 `tomato_english_happy_talking-windows-v1.8.1.zip`，解压后运行 EXE。
- Android：下载 `tomato_english_happy_talking-android-v1.8.1.apk`；当前为项目测试签名侧载包，
  不是应用商店签名。
- 使用 `SHA256SUMS.txt` 校验下载文件完整性。

Windows ZIP 不包含开发者或用户的数据库、API Key、缓存、日志、录音、绘本、歌曲及导出媒体。
Windows 与 Android 正式产物都打包项目声明的本地 Nunito 与图标字体。

> 已保存文章继续读取 `articles.sentences` 中的既有句槽，不会因为本补丁自动重新分句。

## English summary

V1.8.1 is a settings and playback polish release: more Volcengine English teaching/audiobook/CS
voices with an English-only filter, voice settings moved to the top of Settings with a nearby Save
Voice action, live picture-page transitions that follow the recording `pageTransition` setting
(CSS approximations in Web UI), and fullscreen listening that starts from the selected sentence
instead of always restarting at index 0.
