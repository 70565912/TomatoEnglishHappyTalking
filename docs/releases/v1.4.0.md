# Tomato English Happy Talking v1.4.0

发布日期：2026-08-09（Asia/Shanghai）。相对v1.3.0的更新。

## 本次更新

- 发布Syntax V3分句链路，Windows和Android共用UDPipe依存句法解析与候选生成。
- AI复核只允许选择程序提供的候选路径ID，不能重写原文或任意创造切点。
- 该版本新增火山DeepSeek V4 Flash推荐项，作为新配置默认文本模型；已有用户保存的模型配置不强制迁移。
- ASR供应商与模型可独立设置，文本模型设置不替代ASR、TTS或图像服务选择。
- 公开测试与评测中心，补充句法解析器比较、文本模型人工审核、Bridge载荷和Real-ESRGAN同区域图像对比证据。
- 保留已有文章的持久化句槽，新规则在新建或显式重建时应用。

## 下载与升级

- Windows：`tomato_english_happy_talking-windows-v1.4.0.zip`，解压后运行EXE。
- Android：`tomato_english_happy_talking-android-v1.4.0.apk`，项目测试签名侧载包，并非应用商店签名。
- 使用随附`SHA256SUMS.txt`核对下载文件。

Windows安装包不包含本机数据库、缓存、日志、API Key或生成媒体。云服务使用用户自行配置的账号。

## English summary

Ships the Syntax V3 pipeline shared by Windows and Android with UDPipe parsing and constrained AI path selection. This version adds a DeepSeek V4 Flash default for new text-model configurations, independent ASR model settings, and public evaluation reports. Existing saved sentence slots remain unchanged.
