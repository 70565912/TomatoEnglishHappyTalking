# Tomato English Happy Talking v1.0.0

发布日期：2026-07-19（Asia/Shanghai）。首个公开版本。

## 本次更新

- 首个公开版本，提供 Windows 与 Android 客户端；英文或中英文章可按书籍、章节保存在本机。
- 支持章节绘本规划与图片生成、单页指令编辑、逐句听力与缓存TTS、跟读录音和识别评分，以及基于章节的英语对话。
- 支持歌曲导入、歌词字幕时间轴，以及听力/歌曲视频导出，字幕可保存为SRT或嵌入视频；歌曲字幕支持中英文歌词。
- 文章保存包含翻译和首次分镜规划，失败后保留已保存正文并支持续传，保存阶段显示进度。
- Suno使用系统浏览器手动生成并导入本地音乐的流程。
- 采用本地存储和用户自行配置的云服务，无需自建后端；发布安装包排除本机运行数据。

## 下载与升级

- Windows：`tomato_english_happy_talking-windows-v1.0.0.zip`，解压后运行EXE。
- Android：`tomato_english_happy_talking-android-v1.0.0.apk`，项目测试签名侧载包，并非应用商店签名。

Windows安装包不包含本机数据库、缓存、日志、API Key或生成媒体。云服务使用用户自行配置的账号。

## English summary

The first public Windows and Android release provides local book/chapter storage, picture-book creation and editing, cached listening audio, follow-reading and chapter conversation, song import, and subtitle/video export. Article creation preserves saved content on later-stage failures and supports resuming.
