## 解读规则

- 访问增加但下载不变：优先检查价值定位、平台限制、安装步骤和 API 成本说明。
- 下载增加但反馈很少：改善首次使用指引、Discussions 和应用内反馈入口。
- Issue 增加但信息不足：调整 Issue Form 的必填项和脱敏提示。
- Star 增加但下载不变：可能是技术关注而非真实使用，需要结合 Traffic 和 Release 数据判断。
