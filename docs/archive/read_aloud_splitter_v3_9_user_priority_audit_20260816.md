## 1. 本轮确认的规则

本轮裁决只执行 `docs/read_aloud_sentence_split_spec.md`，不使用报告外的语感翻转个例：

- `<=16` 词不因长度强制切分；
- 无标点 `17–20` 词是句法切分弹性区：有低风险舒适边界时可切，切点会制造碎片或割裂确定紧密成分时可 KEEP；
- `>17` 词且含可用原文标点/delimiter 边缘时，必须在可用标点/边缘中切分；
- 无标点 `>20` 词必须切分，句法只负责选择相对安全的位置；
- 完整括号的开缘和闭缘是替代切点；同等合规时优先在闭缘切，把括号并入左块，不要求同时选择两缘；
- 共享主语的并列谓语可在协调连词前切；解析器把并列谓语误挂到外层形容词时，必须用完整左侧主语和
  右侧谓语事实恢复该边界，不能退化为 emergency；
- 闭合主系表/谓语和名词链之后，完整的 `6–16` 词地点或范围介词尾语可从其前缘切分，但 `of/than`
  紧密补语、包含新谓语的右块和超过16词的右块不适用；
- 不制造非功能性1–3词碎片；完整且可独立朗读的短引语不属于非功能性碎片。

`manual-review/**/review-queue.json` 在本轮只作为待讨论输入读取，没有写入人工 decision 或 note。

## 3. 两书全量质量门禁

冻结输入覆盖 Alice 39 章、Willows 62 章，共 101 章、2,927 个原始正字句。两版使用同一输入和同一
规则审计；“不支持原句”取以下集合的并集：仍含 `>20` 词块、`>17` 块跳过可用原文标点、或首选路径
使用切入确定紧密成分的 emergency。

| 指标 | V3.7 基线 | V3.9 候选 |
|---|---:|---:|
| 章节 / 原始正字句 | 101 / 2,927 | 101 / 2,927 |
| 输出分块 | 7,979 | 9,198 |
| 最大块词数 | 27 | 20 |
| 含 `>20` 词块的原句 | 53 | 0 |
| 跳过可用原文标点的原句 | 39 | 0 |
| 选中 emergency 的原句 | 8 | 0 |
| 不支持原句并集 | **90** | **0** |
| 规范化回拼失败 | 0 | 0 |

候选的 2,927 个原句分别只执行一次事实构建和一次 DAG 求解：`sentenceFactBuilds=2927`、
`dagSolves=2927`。新增的 11 个1–3词块全部是完整短引语：`"That you won't!"`、
`"Poor little thing!"`、`"Get up!"`、`"I see!"`、`"Come on then!"`、`"Oh, I know!"`、
`"Two lines!"`、`"Onion-sauce! Onion-sauce!"`、`"Now then!"`、`"More luck!"`、`"Ho, ho!"`；
没有非功能性短碎片。

### 两项残余问题的收口结果

1. `Willows-E25-O24` 现在选择词位30的 `dependencyClause`（risk 0），不再选择
   `could always be counted | upon ...` 这一短语动词/介词补足语内部边界。
2. `Willows-E30-O21` 现在选择词位31的 `dependencyPhrase`（risk 0），不再选择
   `keep | of the stoutest castle ...` 这一名词紧密补足语内部边界。

实现只依据词性、依存结构、长度和局部功能块事实，不读取书名、章节、原文字符串或审核 ID。

与本轮修改前的 V3.9 逐原句比较，2,927 个原句中只有4项首选路径变化：上述两项指定修复，以及
`fallen in love | at first sight ...`、`stretch his legs | in a long ramble ...` 两项同规则下的安全改进。
审计过程中一度出现的 `fine | and biting things` 并列修饰语误切已通过“左侧必须存在真实共享主语”
约束消除，没有进入最终结果。

## 4. 性能与代码量

性能采用 AOT 编译、同机、相同冻结输入、基线/候选交替运行7轮；每轮覆盖 Alice E01/E02 和
Willows E35/E43：

- V3.7 样本（µs）：`1906075, 1917497, 1934366, 1938517, 1945478, 1955075, 2010319`；
- V3.9 样本（µs）：`1618339, 1618942, 1631665, 1634733, 1670223, 1679863, 1753258`；
- 中位数：1,938,517 µs → 1,634,733 µs，V3.9 **快 15.67%**。

生产 V3 Dart 文件物理行数：4,717 → 4,828，增加111行（约2.35%）。候选没有增加第二套求解、递归修复
或额外全文扫描，仍保持一次事实构建加一次有界 DAG；结合不支持原句减少90项和性能提升，符合允许的
小幅功能代码增量条件。
