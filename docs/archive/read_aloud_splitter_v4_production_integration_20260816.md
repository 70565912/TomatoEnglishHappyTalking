# 分句 V4 生产整合迭代记录（2026-08-16）

本文记录 clean-room V4 接入唯一生产入口后的候选轮次。语义规则以
[`read_aloud_sentence_split_spec.md`](../read_aloud_sentence_split_spec.md) 为准，迭代门槛以
[`read_aloud_sentence_split_engineering_rules.md`](../read_aloud_sentence_split_engineering_rules.md) 为准。
本文只保存实验假设、固定输入、结果和淘汰原因，不新增生产规则。

## 固定输入与判定口径

- Alice：`output/sentence-split-v3/alice-v3-audit/alice-v3-report.json`；
- Willows：`output/sentence-split-v3/perf-optimized-full-willows-g1` 至 `g4` 下的四份
  `willows-v3-report.json`；

- 每个正字句必须恰好构建一次事实、执行一次有界 DAG 求解；
- “不支持”由统一规范逐变化句复核，不以 UDPipe crossing、emergency 标签或自动启发式代替；
- 候选只有在不支持数严格少于最近接受轮次、没有显著性能或结构回退时才能接受。达到0后必须保持0，
  并至少改善一个次级指标。

## 生产整合 R7：首次宽版全量基线

- 101章、2,927个正字句；候选输出7,976句；相对冻结生产结果有141个正字句变化；
- 逐项复核确认21个不支持变化：`21 / 141 = 14.894%`，按候选输出为
  `21 / 7976 = 0.263%`；
- 1词句0、超过30词0、最长27词；
- 代表 AOT 回放相对 clean-room 阶段11约快77%，但本轮质量不够，不作为最终生产替换结论。

## R8d / R8e：弱风险直接扣入结构分（失败并撤回）

- 假设：把标点连续性弱风险直接从结构强度中扣除，可以统一修复引语和短尾；
- 结果：部分强结构分被扣成负数，造成大量无关边界漂移；
- 结论：失败。弱标点告警只能作为独立弱证据，不得改变强事实的非负不变量；相关实现已撤回，
  并在现有专项测试中增加所有分项分数不得为负的断言。不得重复此路径。

## R8h：引语归属与 parser 降级修正（接受为3项残留检查点）

- 101章、2,927个正字句、7,925个最终输出；每章事实构建数和 DAG 求解数均等于正字句数；
- 相对 R7 有132个正字句变化，逐项复核后确认3个不支持：
  1. Alice E06 把 `a large pool | all round her` 切开，未使用后方更自然逗号；
  2. Willows E43 的 attribution 后开引号未形成边界，前一块混入长引语；
  3. Willows E57 同类 attribution 后开引号问题。
- 不支持率：`3 / 132 = 2.273%`；按输出为 `3 / 7925 = 0.038%`。严格少于 R7，接受为非零
  改进检查点。

## R8j：长引语开缘与短 attribution（接受为2项残留检查点）

- 分支：`codex/splitter-v4-production-r8j-2-unsupported`；
- 统一修改：
  - 长引语前已有源标点时，把开引号登记为可选标点边界；
  - 完整的短 attribution 可以在后续开引号前独立成块；
  - 介词右续风险只在左侧词类具备真实附着可能时启用，同时保留名词/专名左中心，避免
    `pool | all round` 一类错误；
  - 冒号后的开引号归右块，不把引号错误粘到左块；
  - 弱标点风险和结构强度保持独立，所有评分分量维持非负。
- 针对性测试72/72通过。冻结全量为101章、2,927个正字句、7,970个最终输出；事实构建2,927次，
  DAG求解2,927次，满足一次事实＋一次 DAG 不变量。
- 相对 R8h 有75个正字句变化。73个得到支持，修复了 R8h 的3个残留；另有2个不支持：
  1. Alice E35：原来均衡的 `the Knave was standing before them, in chains, | with ...` 被重排为
     `the Knave was standing before them, | in chains, with ...`，从8/9退化为6/11；
  2. Willows E62：原来完整且均衡的 `but Toad, in a mild way, was rather snubby to him, | remarking ...`
     被重排为 `but Toad, in a mild way, | was rather snubby ...`，为修正后方引语开缘而移动了上游合规
     标点锚点。
- 不支持率：`2 / 75 = 2.667%`；按最终输出为 `2 / 7970 = 0.025%`。虽然变化集比例略高于 R8h，
  绝对不支持数由3降到2，符合本项目的严格下降主门槛，接受为下一轮基线，但不得写成归零。
- 结构规模：以基点的生产3文件、回放器和4个重复实验事实文件为同一功能口径，功能代码从5,330行
  降到4,803行，净减527行（-9.89%）。旧实验事实/格点实现已并入生产模块并删除，没有保留第二套
  求解链路。
- 本轮全量报告：
  `production-integration-r8j-full-a.json`、
  `production-integration-r8j-full-w1-frozen.json` 至
  `production-integration-r8j-full-w4-frozen.json`。

## R8n16：统一表面结构事实与有界候选覆盖（接受为归零检查点）

- 分支：`codex/splitter-v4-production-r8n16-zero`；
- 最近接受基线：R8j，commit `d1b4273`，残留不支持数2；
- 最终报告：`production-integration-r8n16-final-full-a.json`、
  `production-integration-r8n16-final-full-w1.json` 至
  `production-integration-r8n16-final-full-w4.json`；
- 统一修改：
  - 表面词类事实补足 parser 错挂时仍可验证的短比较结构、分词后置结构和补充介词短语；
  - `PRON | NOUN/PROPN` 这类限定语与中心词内部边界作为通用硬阻止，不读取书名、章节或词语白名单；
  - Top-K 仍固定为24，前8条原始排名不被覆盖替换；补充首边界覆盖时保留每个首边界的最少切点代表，
    避免为了候选多样性丢掉更简单的合法路径；
  - 单次 DAG 完成后，只有存在稳定路径时才从对外候选中移除含明确
    `incomplete_constituent_boundary` 的路径；没有稳定路径时保留紧急回退。没有第二次事实构建、第二套
    DAG、递归修复窗或求解后重排。

### 结构与平台门禁

- 与R8j比较，3个生产文件原始行数从3,997增至4,198，净增201行（+5.03%）；其中主体 solver
  从2,842减至2,699，净减143行，新增事实和有界候选职责分别留在独立 facts/lattice 模块。按R8j
  已记录的完整功能口径为 `4,803 → 5,004`（+4.18%），仍比重构前5,330行少326行（-6.12%）；
  本轮以该小幅增量换取不支持数归零以及E02/E30端到端加速，符合“质量优异或速度显著时允许小幅
  功能增量”的门槛；
- 生产代码没有书籍/章节/目标词字面量，没有新增无界递归、重复扫描管线或第二套求解器；
- 全 App `flutter analyze` 只有重构前已登记的3个无关 `unused_element` warning，本轮新增问题0；
  `dart format` 与 `git diff --check` 通过；
- Windows原生使用生产模型通过243项；Android和Windows插件均调用
  `packages/udpipe_parser_v3/native/udpipe_parser_v3_core`，并由同一
  `UdpipeSyntaxParserV3.expectedModelSha256` 校验同一打包模型；分句事实和DAG求解为同一份纯 Dart
  代码且无平台分支。本轮没有修改Android或Windows原生代码。

### 已拒绝路径

1. 在构建候选时全局删除所有带 incomplete 标记的路径会丢失合法的首边界覆盖，已撤回；最终只在
   单次有界求解之后、确有稳定替代路径时过滤，并保留无稳定路径时的紧急回退；
2. 直接把所有 `VERB | as + 主语 + 谓语` 视作比较参照从句过宽，曾扩散到
   `do | as I do` 与 `deepening | as they realised`，已撤回；最终要求谓语前至少存在两个名词性/代词
   成分，只覆盖可解释的参照结构；
3. 为补齐首边界覆盖而任意替换Top-K尾项，会删掉同一首边界的最少切点路径，已撤回；最终保护前8条
   原始排名和每个首边界的最少切点代表。不得重复上述三条失败实现。

## 当前结论

R8n16达到当前目标：最近接受基线的不支持切法由2降为0，并在0处保持全量可解释；质量、性能和结构
三项门禁全部通过。该结论只批准生产求解代码检查点，不授权数据库迁移、旧文章重分、TTS重建或媒体
替换。
